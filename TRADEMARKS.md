# Marcas

El código de este repositorio es software libre bajo la licencia indicada en `LICENSE`
(o `COPYING`). **La licencia cubre el código, no las marcas.**

«**NoctiVulp**», el nombre de esta aplicación y sus logotipos e iconos identifican las versiones
oficiales publicadas por NoctiVulp. No se conceden derechos sobre ellos (GPLv3, sección 7, apartado e).

## Qué se puede hacer

- Usar, estudiar, modificar y redistribuir el código según su licencia.
- Redistribuir el programa **sin modificar** y decir con exactitud de dónde viene
  («compilado del código de NoctiVulp, versión X»).
- Mencionar el nombre para referirse al proyecto original: en reseñas, tutoriales, artículos o
  en la documentación de un fork («basado en …»).

## Qué no

- Publicar una versión **modificada** con el mismo nombre, logotipo o icono. Un fork lleva
  nombre e identidad visual propios.
- Presentar una compilación propia como si fuera la oficial, o insinuar el respaldo de NoctiVulp.

## Versiones oficiales

Las compilaciones oficiales se publican a través de los canales de NoctiVulp, como
[Patreon](https://www.patreon.com/cw/NoctiVulp) y las *releases* de este repositorio cuando las
haya, y van firmadas.

Para cualquier duda sobre el uso del nombre, abre un *issue*.
