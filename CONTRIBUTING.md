# Cómo contribuir

Gracias por el interés. Estas son las condiciones para aportar a este repositorio.

## Licencia de los aportes

Lo que aportes se publica **bajo la misma licencia que el repositorio** (ver `LICENSE` o
`COPYING`). No hay acuerdo aparte que firmar ni se ceden derechos: conservas la autoría de tu
aporte y lo compartes en las mismas condiciones que el resto del proyecto.

## Certificado de origen (DCO)

Cada commit lleva una línea `Signed-off-by`. Con ella declaras que cumples el
[Developer Certificate of Origin 1.1](https://developercertificate.org/): que el aporte es tuyo,
o que tienes derecho a enviarlo bajo esta licencia.

```bash
git commit -s -m "Describe el cambio"
```

No se aceptan aportes con código copiado de proyectos de licencia incompatible, ni recursos
(imágenes, datos, modelos, sonidos) cuyo origen no esté claro.

## Qué se acepta

- **Issues**: errores reproducibles, con pasos, versión y sistema.
- **Pull requests**: correcciones y mejoras **con contenido**: funciones, arreglos, rendimiento,
  traducciones completas. Los cambios que solo tocan colores, textos o gustos personales se
  discuten antes en un *issue*.
- Antes de un cambio grande, abre un *issue* para acordar el enfoque.

## Forks

Puedes hacer un fork cuando quieras: la licencia lo permite. Si lo redistribuyes modificado,
usa un nombre y un icono propios (ver `TRADEMARKS.md`).
